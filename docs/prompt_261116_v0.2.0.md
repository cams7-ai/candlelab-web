# Prompt de implementação — CandleLab Web 0.2.0

Referência: `../candlelab-docs/tutorial_estrategias_cripto_candles/tutorial_estrategias_cripto_candles.md`.
Decisão do usuário: simular todas as 18 estratégias com importação de dados auxiliares.

Execute este documento sobre o projeto existente:

1. Publicar versão 0.2.0 e manter os fluxos existentes de datasets, sessões e processamentos.
2. Consumir o catálogo da API com 4 estratégias legadas e as 18 do tutorial. Mostrar categoria, regras, limitações e requisitos de dados. Os padrões e campos vêm do catálogo.
3. Permitir importar arquivo JSON e editar dados auxiliares por processamento. Exibir os campos necessários à estratégia, validar JSON antes do envio e enviar o snapshot exatamente no contrato definido pela API. Não simular dados ausentes silenciosamente.
4. Exibir os parâmetros e indicadores novos nos painéis corretos (preço, osciladores, volatilidade, volume). Preservar sinais e fills distintos, aquecimento como lacunas e horários UTC.
5. Atualizar fixtures de demonstração para o catálogo real; manter indicação de resultados sintéticos. Atualizar README e registro de validação.
6. Verificar build TypeScript/Vite, testes existentes e testes dos novos fluxos de importação, erros e envio de parâmetros. Não incorporar resultados selecionados do tutorial como backtests reais.

Critério de entrega: interface integrada às 22 opções publicadas pela API, importação funcional, mensagens acionáveis e versão 0.2.0.
